# Notebook phân tích

| Notebook | Mục đích |
| --- | --- |
| 01_eda_vi.ipynb | Phân tích khám phá dữ liệu Home Credit, trình bày tiếng Việt |
| 02_partition_validation.ipynb | Kiểm tra kết quả chia client |
| 03_relational_partition_audit.ipynb | Đọc và trình bày kiểm toán phân bổ bảng quan hệ |

Notebook phục vụ phân tích và giải thích; pipeline huấn luyện chạy qua [scripts](../scripts/README.md). Kiểm tra đường dẫn dữ liệu ở các cell đầu trước khi chạy và dùng kernel của môi trường project. Công cụ notebook/Jupyter có thể cần cài thêm, chưa được liệt kê trong requirements.

Chuẩn bị dữ liệu hoặc báo cáo mà notebook đọc trước khi chạy. Output lưu trong notebook có thể thuộc lần chạy cũ; chạy lại để đối chiếu dữ liệu hiện tại. Script 08 có thể tạo lại notebook audit.

Notebook nguồn tiếng Anh 01_eda.ipynb và cache dịch hiện không có; hai tiện ích dịch cũ trong scripts không chạy đầy đủ với trạng thái này.
